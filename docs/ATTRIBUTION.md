# Source attribution

TechSearch keeps result titles, excerpts, code segments, author identity when available, original links, and source-provided licenses. For MDN pages, the attribution points to the original page and its contributor history. Check source pages for exceptions and code-sample terms.

- MDN documentation and contributor attribution. [MDN content licensing](https://developer.mozilla.org/en-US/docs/MDN/Writing_guidelines/Attrib_copyright_license)
- Stack Overflow questions and answers retain the recorded content license where the export supplies it. Legacy records can lack a user profile ID. [Stack Overflow content licensing](https://stackoverflow.com/help/licensing)
- Browser compatibility data is used as metadata and retains its pinned revision. [MDN browser-compat-data repository](https://github.com/mdn/browser-compat-data)
- The configured sentence encoder’s local snapshot includes its model card and available license files. [All-MiniLM-L6-v2 model card](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)

The bundle is for local demonstration. Review the source and model terms before distribution and avoid publishing user runtime files or private evaluation materials.
